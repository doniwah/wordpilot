
# WordPilot

**An open-source AI writing assistant for Microsoft Word.**

WordPilot helps you write better documents directly inside Microsoft Word using AI-powered writing tools and flexible AI provider integrations.

## Features

- AI-powered text rewriting
- Grammar and spelling improvement
- Paraphrasing
- Academic writing assistance
- Continue writing
- Text summarization
- Translation
- Multiple AI provider support
- Local AI support through Ollama

## AI Providers

- Google Gemini
- OpenAI
- Anthropic Claude
- Ollama
- Custom OpenAI-compatible endpoints

## Architecture
